Arcoline — Release notes

What changed in each release, newest first. Download the latest version or read the user manual.

1.1.5 — August 15, 2026

Bug fixes for the standalone app on both platforms, and for the plugin in hosts that never roll a transport. If you run Arcoline as a VST3 or AU inside a DAW with a normal transport, nothing changes for you.

  • The standalone now measures — Windows and macOS. Integrated LUFS, RANGE, PLR, the peak/RMS max-holds, true-peak max and its over-flag, and the history graph all sat frozen for the life of the session. The live meters — peak, RMS, correlation, balance, M/S, momentary and short-term LUFS — kept working, so the app read as a feature-limited build rather than a broken one. The cause: those measurements belong to a measurement session that follows the host transport, and the app mistook its own internal playhead for a DAW transport that never starts rolling, so the session never began.
  • Same fix covers plugins in hosts with no rolling transport. A live-performance host such as GigPerformer reports a playhead that never rolls, which stalled the session the same way. Those measurements run now.
  • Audio input works on macOS. The standalone shipped without the microphone usage declaration macOS requires, so the system silently refused every input request. It now declares it properly and macOS prompts on first launch — allow it. Arcoline reads that input only to display metering; nothing is recorded, stored or transmitted.
  • The macOS installer no longer skips the standalone. If you already had a copy of Arcoline.app outside /Applications/Audivea/, the installer would quietly update that copy instead. It now always installs where it says it does.

One thing worth knowing: with no transport to follow, the session now runs continuously — so signal you monitor before pressing play counts toward the reading, and Auto-reset on play is off by default, so it stays in when playback starts. Turn it on in Settings if you want each pass to start clean.

1.1.0 — August 1, 2026

New: HISTOGRAM view in Dive

A third posture on Dive's centre instrument, alongside LOUDNESS and PHASE: a time-at-level histogram — how much time your material spent at each level, drawn on the dial's own printed axis so the shape sits directly against your delivery target notch and tolerance band. Our most-requested feature since launch.

  • Two axes — momentary LUFS (400 ms) or plain RMS dBFS (100 ms). Both accumulate in parallel, so switching units never loses data.
  • MEDIAN hero + P10/P95 spread caliper show where the material sits and how wide it spreads. (The caliper is a display reading of the on-screen shape — the report card's RANGE remains the EBU TECH 3342 loudness range.)
  • The axis adapts, you don't — the printed floor derives from your target and material (−36, stepping to −48 when needed). No range knob to manage.
  • An honest lamp — [ SETTLING ] marks a shape built from too little material and clears once a level has genuinely accumulated 3 seconds of dwell.
  • In RMS units the LUFS-specific target chrome fades out rather than mislabel a dBFS axis; a live RMS caret takes over as the reference.
  • Your posture and unit choice persist with the session.

The histogram follows the measurement session exactly like Integrated and RANGE: it pauses with a parked transport, clears with RESET, and rebuilds each pass when you loop a section. Colour in the histogram encodes dwell time only, never level. The manual covers it in full.

Under the hood

  • The goniometer feed no longer runs while the scope is hidden, trimming per-frame UI work.
  • DSP test suite extended to 3,800+ assertions, including a characterization suite pinning the shipping LRA number bit-for-bit.

1.0.1 — July 12, 2026

  • Fixed: metering in hosts that deliver variable-size audio blocks — notably FL Studio.

1.0.0 — July 10, 2026

The first release. One calm instrument for the whole delivery check:

  • Loudness to ITU-R BS.1770-4 — Momentary, Short-term and gated Integrated LUFS with Max M / Max S holds.
  • True peak (inter-sample, oversampled) with a sticky session “over” flag; per-channel peak & RMS with peak-hold and clip detection.
  • Dynamics — PSR, PLR and EBU TECH 3342 loudness range.
  • Stereo — goniometer, phase correlation and L/R balance. Tonal balance — low / mid / high energy split over the session.
  • Two views — Dive (the full workbench) and Ascend (the at-a-glance verdict) — with built-in loudness targets for streaming, broadcast, film and podcast, plus custom targets.
  • Measurement sessions linked to the host transport, honest true-peak flagging while parked, and full accumulation during offline bounces.
  • Copy-to-clipboard and CSV export of every reading; three themes and a colour-blind-safe overlay.
  • VST3 · AU · Standalone, for macOS (universal) and Windows.
